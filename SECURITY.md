# Security

Only the latest published release receives fixes. Alpha software is still being
hardened. Agents can access your local workspace; review actions and content
before publishing. Do not expose the local server publicly or share provider logins.

Report vulnerabilities through [private GitHub advisories](https://github.com/alonsosolisg/makepace/security/advisories/new).
If private reporting is unavailable, request a private contact in an issue
without disclosing vulnerability details. Include affected version, OS, steps and
impact. Never put credentials or client content in public issues or logs.
There is no guaranteed response SLA or bug bounty.

OS encryption protects stored secrets, not a compromised computer. External
research is untrusted input, not permission to act. Updates open the official
release page and require manual installation.

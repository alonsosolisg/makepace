# Changelog

## 0.2.0-alpha.1

First open-source desktop alpha, under Apache 2.0.

- TypeScript source, reproducible build, linting, type checks and Prettier.
- Windows x64, macOS Apple silicon/Intel, and Linux x64 installers.
- GitHub Releases distribution and an explicit in-app update check.
- Website onboarding, format research, batch review and approved OneUp scheduling.
- Encrypted local OneUp/Apify credentials and user-owned Codex authentication.

Installers are unsigned. Updates require downloading the new installer; there is
no automatic installation. App data stays outside the installation directory.
Back it up before upgrading from private 0.1.0 builds.
